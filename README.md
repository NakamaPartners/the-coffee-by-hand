# The Coffee by Hand

An editorial, responsive React/Vite site for The Coffee by Hand in Duluth, Georgia.

## Run locally

```bash
pnpm install
pnpm dev
```

## Production build

```bash
pnpm build
pnpm preview
```

## Media compatibility

The two hero videos include both VP9/WebM sources for Chromium-based browsers and H.264/MP4 fallbacks for Safari and iOS. Poster images are included for immediate visual fallback while video metadata loads.
